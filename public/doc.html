2. Типы данных

2.1 Родители (группы / виды растений)

Приходят из /api/templates/roots. Содержат только idGroup и nameGroup:

export type TemplateGroup = {
  idGroup: number;
  nameGroup: string;
  subRows?: Template[];   // дети приходят из /children
};

2.2 Дети (конкретные растения)

Приходят из /api/templates/:idGroup/children. Полная структура:

export type Template = {
  idTemplate: number;     // уникален, используется как getRowId
  nameTemplate: string;
  idGroup: number;
  nameGroup: string;
  status: number | null;  // 1=создан, 2=выполнен, 3=ошибка, 4=выполняется
  dateCreate: string;     // формат ДД.ММ.ГГГГ
  subRows?: Template[];
};

2.3 Union-тип для MRTTree

export type TemplateTreeNode = TemplateGroup | Template;

// Type guard: группа = нет idTemplate
const isGroup = (row: TemplateTreeNode): boolean => !('idTemplate' in row);
const isChild = (row: TemplateTreeNode): row is Template => 'idTemplate' in row;
Проверка «это группа?» должна быть !('idTemplate' in row), а не row.idGroup === row.idTemplate — у TemplateGroup нет idTemplate, поэтому сравнение всегда false, и стрелки не будут работать.

4.3 Запуск

11. Цвета строк по статусу

СтатусЗначениеФон
1Созданпрозрачный (обычный)
2Выполненrgba(76, 175, 80, 0.12) — светло-зелёный
3Ошибкаrgba(244, 67, 54, 0.10) — светло-розовый
4Выполняетсяrgba(33, 150, 243, 0.10) — светло-голубой
const STATUS_BG: Record<number, string | undefined> = {
  1: undefined,
  2: 'rgba(76, 175, 80, 0.12)',
  3: 'rgba(244, 67, 54, 0.10)',
  4: 'rgba(33, 150, 243, 0.10)',
};

const getRowBackgroundColor = (row: TemplateTreeNode): string | undefined => {
  if (!isChild(row)) return undefined;           // у групп статуса нет
  if (row.status === null) return undefined;
  return STATUS_BG[row.status];
};
Цвета заданы в rgba с низким alpha — работают в светлой и тёмной теме. При hover/selected применяется filter: brightness(), чтобы не перекрывать кастомный фон.

12. Поле поиска и его скрытие

12.1 Как это работает

Поле поиска — это MRT_GlobalFilterTextField внутри <Collapse orientation="horizontal">. Иконка-лупа (справа от поля) переключает showSearch state.

12.2 Скрыть поиск полностью

В createToolbarConfig({...}) в ParentPage.tsx:

showSearchButton: false,   // ← иконка-лупа не рендерится
initialShowSearch: false,  // ← поле поиска не открывается
Оба поля false → в тулбаре нет ни иконки, ни поля. Параметр searchTerm уходит на сервер как пустая строка → сервер возвращает все данные без фильтра.

13. Серверная пагинация / поиск / сортировка

13.1 Состояние в ParentPage

const [pagination, setPagination] = useState<PaginationState>({ pageIndex: 0, pageSize: 10 });
const [sorting, setSorting] = useState<SortingState>([]);
const [searchInput, setSearchInput] = useState('');
const debouncedSearch = useDebouncedValue(searchInput, 400);

  return {
    size: pagination.pageSize,
    offset: pagination.pageIndex * pagination.pageSize,
    sortDirection: (sort?.desc ? 'DESC' : 'ASC'),
    sortField: sort?.id ?? 'idGroup',

13.3 Как работает debounce

function useDebouncedValue<T>(value: T, delay = 400): T {
  const [debounced, setDebounced] = useState(value);
  useEffect(() => {
    const t = setTimeout(() => setDebounced(value), delay);
    return () => clearTimeout(t);
  }, [value, delay]);
  return debounced;
}

400 мс — оптимально для серверного поиска. Увеличьте до 600–800 мс при медленном сервере.

13.4 Сортировка дат

Поле dateCreate в формате ДД.ММ.ГГГГ. Сервер парсит его в timestamp для корректной сортировки:

function parseDate(s: string): number {
  const [d, m, y] = s.split('.').map(Number);
  return new Date(y, m - 1, d).getTime();
}

14. Ленивая загрузка детей

14.1 Механизм

  1. Клик на стрелку группы → onExpandedChange → expanded меняется.
  2. useEffect в Tree.tsx видит: строка раскрыта, getSubRows(row) === undefined, canExpand(row) === true → вызывает loadChildren(row).
  3. HTTP-запрос на /api/templates/:idGroup/children.
  4. Пока промис не разрешён — isLoading = true, MRT показывает лоадер.
  5. Ответ → withSubRows(row, children) → setData → дети рендерятся.
  6. Ошибка → finally снимает isLoading, subRows остаётся undefined → повторный клик запустит запрос снова.

14.2 Функции в ParentPage

const canExpand = useCallback(
  (row: TemplateTreeNode) => isGroup(row),
  [],
);

const loadChildren = useCallback(
  async (row: TemplateTreeNode): Promise<TemplateTreeNode[]> => {
    if (!isGroup(row)) return [];
    const res = await fetch(`/api/templates/${row.idGroup}/children`);
    if (!res.ok) throw new Error(`HTTP ${res.status}`);
    const json = (await res.json()) as { rows: TemplateTreeNode[] };
    return json.rows;
  },
  [],
);

17.2 Принцип центрирования тулбара

Правая группа кнопок позиционируется абсолютно:

<Box
  sx={{
    position: 'absolute',
    top: '50%',
    right: TOOLBAR_CONTENT_RIGHT_OFFSET,
    transform: `translateY(calc(-50% + ${TOOLBAR_CONTENT_OFFSET_DOWN}px))`,
    height: TOOLBAR_CONTENT_HEIGHT,
    display: 'flex',
    alignItems: 'center',
  }}
>
  {/* Collapse + поиск + иконка + правая панель */}
</Box>
padding на контейнере тулбара не помогает — MRT оборачивает содержимое в несколько flex-обёрток с alignItems: center. Абсолютное позиционирование обходит их все. TOOLBAR_CONTENT_OFFSET_DOWN = 0 — ровно центр, положительное значение — ниже центра, отрицательное — выше.
